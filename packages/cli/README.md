# @payoutjp/cli

Local UTF-8 JSON validation for one Bank destination with deterministic text/JSON output and CI exit
codes.

```sh
npm install --global @payoutjp/cli@alpha
payoutjp --help
```

No production Bank Registry is bundled. The CLI does not verify account existence, recipient
identity, or payment success. See the [PayoutJP repository](https://github.com/inthecradle/payoutjp)
for usage and limitations. Licensed under Apache-2.0.
